# Загварын дахин тохируулга · 2026-11-15

## Төлөв

Энэ салбар нь турших тооцоо болон түүнийг зөв тайлбарлах дэлгэцийн өөрчлөлтийг
агуулна. Кодын тест тэнцэх нь загварын нарийвчлал сайжирсны баталгаа биш.
Таталт, хуучин загварын давтан тооцоо, шинэ хувилбарын бие даасан шалгалт
дуусаагүй үед шинэ коэффициент, шинэ нарийвчлалын тоо нийтлэхгүй.

## Давтаж шалгах

Эх код: `f36d9d8b9ff6b692d624e9a0aa45d02e314fd117`.
Өөрчлөлтгүй хуулбар дээр `calibrate.py prep`, `fire`, `dust`, `flood`, `uinput`
дарааллаар ажиллуулна. Эхлээд хэвлэгдсэн загварын суурь давтамж, AUC,
ажиглагдсан тохиолдлын тоо, загварын алдааг давтан үр дүнтэй харьцуулна.
Зөрвөл шалтгааныг тогтоох хүртэл шинэ загварыг ашиглалтад авахгүй.

Шинэ хувилбарыг тусдаа хуулбар дээр ажиллуулах команд:

```text
python pipeline/audit_cache.py cache_audit.json
python pipeline/calibrate.py fire --refit
python pipeline/calibrate.py dust --refit
python pipeline/calibrate.py uinput
```

`--refit` байхгүй бол хуучин шинжүүдийн зохион байгуулалтыг ашиглана.
Зураг гаргахдаа коэффициентийн хадгалсан арга, он/сарын мэдээллээр хувилбарыг
сонгоно. Шинэ коэффициенттэй бол бүх түүхийг дахин тооцох шаардлагатай.

## Турших өөрчлөлт

- Түймэр: `(min(year, last_training_year) - 2013) / 10` оны гишүүн.
  2018–2025 оны шалгалтад хязгаар нь 2017; ашиглалтад 2025. Ирээдүйн он руу
  шугаман экстраполяц хийхгүй. Чиг хандлагад энэ гишүүний нөлөө орно.
- SPI-1: нүд, календарийн сар бүрийн эерэг хур тунадаст байршил 0 бүхий
  гамма тархалтын maximum-likelihood тохируулга; тэг тунадасны магадлал `q`;
  `H(x) = q + (1-q) G(x)`, дараа нь хэвийн тархалтын урвуу функц.
  Тохируулгад зөвхөн сургалтын онууд орно. Өдрийн загвар өмнөх бүрэн сарын
  SPI-г ашиглана, ингэснээр ирээдүйн өдрүүдийн хур тунадас орохгүй.
- Тоос: 2019–2023 оны бүх сар, сарын sin/cos гишүүн; 2024–2026 оны байгаа
  ажиглалтаар шалгана (2026 нь аравдугаар сараар дуусна).
- Тоосны салхины хугарлын цэг: `9.8 - 0.9 * bare_fraction` м/с.
  Энэ шугаман холболт нь бидний турших сонголт; нүд бүрт хэмжсэн босго биш.
- Мэдээлэлгүй галын ажиглалтыг шинэ тохируулгад галгүй өдрийн тоонд оруулахгүй.

## Эх сурвалж, хязгаарлалт

1. [WMO, SPI User Guide (2012), WMO-No. 1090](https://www.droughtmanagement.info/literature/WMO_standardized_precipitation_index_user_guide_en_2012.pdf):
   оршилд 20–30 жилээс эхлэх тухай, бусад хэсэгт 30 ба түүнээс урт хугацааг
   зөвлөдөг; 30-аас богино хугацааг итгэл султай ашиглаж болохыг мөн тайлбарласан.
   Энд ашиглалтын суурь 25, шалгалтын сургалтын суурь 17 жил тул энэ хязгаар
   хэвээр. Түгээмэл 30 жилийн стандарт суурьтай болсон гэж тайлбарлахгүй.
2. [Copernicus EDO/GDO SPI factsheet (үзсэн: 2026-11-15)](https://drought.emergency.copernicus.eu/data/factsheets/factsheet_spi.pdf):
   гамма CDF, тэг тунадасны засвар, хэвийн квантиль; 0.01 мм-ээс бага утгыг
   тэг, 10-аас цөөн эерэг ажиглалтыг дутуу гэж үздэг. Copernicus нь L-момент,
   энд MLE ашигладаг тул тэдний бүтээгдэхүүнийг яг давтаж байна гэж үзэхгүй.
   Манай 15 нийт ажиглалтын нэмэлт босго нь тооцооны хамгаалалт, уур амьсгалын
   суурийн хангалттай уртын баталгаа биш. Тохируулга бүтэхгүй бол SPI NaN;
   нийлмэл түймрийн тооцоонд хуурайшлын нэмрийг хэвийн утгаар орлуулдаг.
3. [SciPy gamma](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.gamma.html):
   вектор MLE-ийн үр дүнг `gamma.fit(..., floc=0)`-той бие даасан тестээр тулгасан.
4. [Kurosaki & Mikami (2007)](https://doi.org/10.1029/2006JD007988), бүтэн эхийн
   5.1 болон дүгнэлт: Говийн `ut5% = 8.9 ± 2.2`, хойд хээрийн
   `9.8 ± 2.2` м/с. Бүсийн дундаж утга, тархалтыг нүд бүрийн нарийн босго
   гэж ойлгохгүй. `9.8 - 0.9 * bare_fraction` нь өгүүллийн тэгшитгэл биш.

## Хүлээн авах шалгалт

Хуучин ба шинэ хувилбарыг ижил ажиглалт, ижил шалгалтын хугацаагаар харьцуулна.
Тоосны бүх улирлын AUC-г хуучин хаврын AUC-тай шууд харьцуулахгүй; эхлээд
MAM (3–5 сар)-ын үзүүлэлт, дараа нь бусад улирлын үр дүнг тайлбарлана.
Түймрийн AUC буураагүй, тохируулгын зөрүү багассан эсэхийг шалгана.
POD, FAR, CSI, яг магадлалаас тооцсон Brier, сургалтын суурьтай харьцуулсан
Brier skill, тооцоолсон/ажиглагдсан тохиолдлын харьцааг хамтад нь уншина.
Үр дүн хангалтгүй бол шинэ хувилбарыг нийтлэхгүй, туршилтын үр дүнг хадгална.

Шинэ `brier_exact` нь хуучин `brier`-ийн ангийн төвөөр ойролцоолсон тоотой
ижил хэмжилт биш. Харьцуулалтын хүснэгтэд тэдгээрийг ялгана.
Түүхэн суурь / шалгалтын үеийн ажиглагдсан давтамжийн харьцаа дангаараа
загварын таамгийн хазайлтыг хэмжихгүй; яг таамагласан магадлалын нийлбэрийг
ажиглагдсан тохиолдлын тоонд харьцуулж шалгана.
