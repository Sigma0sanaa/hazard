## 3. Үлдсэн ажил (дарааллаар)

### 3.1 Түймрийн суурь давтамжийг дахин тохируулах (Earth Engine шаардана)

**Асуудал.** `pipeline/model.json` → `fire.base = 0.0001784` нь 2001–2025 оны дундаж (нэг 0.1° нүд, нэг өдөрт MODIS гал илрэх магадлал). Гэвч гал цөөрсөн: 2001–2017 онд жилд ≈1,580 нүд-өдөр, 2018–2025 онд ≈410 (`verification.n = 3284` / 8 жил). 2018–2025 оны ажиглагдсан давтамж = 3284 / (18,467 нүд × 2,922 өдөр) = 0.0000609, өөрөөр хэлбэл суурийн 1/2.93. Загварын `u_model = 15.8` оноо нь бараг бүхэлдээ энэ нэг чиглэлтэй хазайлт (20·log₄(2.93) = 15.5), санамсаргүй алдаа биш.

**Одоо сайт дээр юу хийсэн (түр шийдэл, тооцоо дахин ажиллуулалгүй).** Үг хэллэгийг засаж, зөрүүг ил бичсэн (доорх 4-р хэсгийг үз). Оноо өөрөө өөрчлөгдөөгүй.

**Жинхэнэ засвар.** `pipeline/calibrate.py`-д цаг хугацааны өөрчлөлтийг оруулна. Хоёр сонголт:
1. *Энгийн:* `fire()` дотор үйлдвэрлэлийн загварыг бүх оноор биш, сүүлийн 10–12 жилээр (жишээ нь 2014–2025) тохируулах, `base`-ийг мөн тэр хугацаагаар авах. Сул тал: сургалтын гал цөөрнө.
2. *Илүү зөв:* `fire_design`-д оны шугаман гишүүн (жишээ нь `(year − 2013) / 10`) нэмж, шалгалтын онуудад найдвартай байдлын зөрүү (`verify()` доторх `gaps`) 0 орчим болсныг шалгах. Ирээдүй рүү экстраполяц хийхгүйн тулд гишүүнийг сүүлийн сургалтын оны утгаар хязгаарлана.

Алхам:
```bash
# 26 жилийн кэш хэрэгтэй (≈ хэдэн GB). Байршил: HAZARD_CACHE орчны хувьсагч, эсвэл репогийн хажуугийн ../gee_cache
# Кэш байхгүй бол pipeline/fetch_era5.py, fetch_obs.py, fetch_static.py-г Earth Engine нэвтрэлттэй ажиллуулж татна (docs/GEE_SETUP.md, docs/GEE_DATA_FORMAT.md).
pip install -r pipeline/requirements.txt
earthengine authenticate            # төсөл: sigma-513109 (EE_PROJECT)
cd pipeline
python calibrate.py prep            # FWI, сарын бороо
python calibrate.py fire            # model.json-д fire.beta, base, verification, u_model бичнэ
python calibrate.py uinput          # оролтын алдааны хүснэгт
python build.py                     # data/gee-г бүх оноор дахин бичнэ (урт)
```
Шалгах: `model.json` → `fire.u_model` 15.8-аас мэдэгдэхүйц буурсан (≈5–8), `auc` 0.90 орчим хэвээр. Дараа нь `js/meaning.js` → `SCORE_MODEL.fire.base`, `seen` утгыг `model.json`-оос шинэчилж, `tests/meaning.test.mjs` тэнцэхийг үз. `js/methods.js` → fire.limits-ийн «≈400, өмнө нь ≈1700» мөрийг шинэ тоогоор соль.

### 3.2 Түймрийн «SPI»-г жинхэнэ SPI болгох (Earth Engine шаардана)

**Асуудал.** `pipeline/calibrate.py` → `monthly_spi()` нь сарын борооны `(r − дундаж) / стандарт хазайлт`-ыг тооцдог. Энэ нь SPI биш: SPI нь сар бүрийн бороонд гамма тархалт тааруулж, хэвийн тархалтын квантиль руу хөрвүүлдэг (McKee нар 1993; WMO-No. 1090). Монголын хуурай саруудад бороо хазгай тархалттай тул энгийн z-оноо −1.5-аас доош бараг гардаггүй, өөрөөр хэлбэл `spi_class()`-ийн 5-р анги (хүчтэй ган) хүрэх боломжгүй болдог. Жин нь бага (2/21) тул онооны нөлөө бага ч нэр нь буруу.

**Одоо хийсэн.** Арга зүйн цонхонд «SPI» биш «борооны стандартчилсан хазайлт» гэж нэрлэсэн.

**Жинхэнэ засвар.** `monthly_spi()`-д сар, нүд бүрээр гамма тааруулалт (тэг бороотой сарын хувийг тусад нь тооцно: H(x) = q + (1 − q)·G(x)), `scipy.stats.gamma.fit(..., floc=0)` ба `norm.ppf`. `model_fire.npz`-д `spi_mu`, `spi_sd`-ийн оронд гаммагийн параметр (`shape`, `scale`, `q`) хадгалж, `pipeline/scores.py` → `fire_S_month()`-ийг мөн адил өөрчилнө. Дараа нь 3.1-ийн алхмаар дахин тохируулна. `pipeline/requirements.txt`-д `scipy` нэмнэ.

### 3.4 Жижиг ажлууд (Earth Engine шаардахгүй)

- `README.md`: дээд хэсэгт шинэ хувилбар, доор нь «өмнөх хувилбарын тайлбар» гэж хоёр гарчигтай давхардсан. Хуучин 22 цэгийн хэсгийг хасаж нэг болго. «32 unit tests» → 72.
- `docs/METHODS.md`-ийн эхний «Wildfire / Dust storm / Flood / Polygon risk tool» хэсгүүд хуучин 22 цэгийн загварыг тодорхойлдог (одоогийн улсын зураг `pipeline/`-аар тооцогддог). Тэдгээрийг «Earlier point version (still used by the mine dust tool)» гарчгийн доор шилжүүл.
- `.github/workflows/pages.yml` → «Build live data» алхам (`scripts/build-latest.mjs`) `data/latest.json` бичдэг. Үүнийг одоогийн хуудас уншдаг эсэхийг `grep -rn "latest.json" js/`-ээр шалга; уншдаггүй бол алхмыг, `js/risk.js`, `js/fwi.js`, `js/openmeteo.js`, `js/firms.js`-ийн ашиглагдахгүй хэсгийг хас (тестүүд нь `tests/risk.test.mjs`, `tests/fwi.test.mjs`).
- `js/ui_text.js`-д динамикаар бүтдэг түлхүүрүүдийг (`fa_step_*`, `da_v_*`, `fi_c_*` г.м.) бодитоор ашиглагддаг эсэхийг нэг бүрчлэн `grep`-ээр шалгаж, үхсэнийг хас.
- Талбайн цонхны «Талбайн хэмжээ» нь өгөгдөлтэй хэсгийн талбай (хилийн гадна талыг хассан), зүүн самбарын «Сонгосон талбай» нь зурсан хайрцгийн бүтэн талбай: нэрийг «Өгөгдөлтэй талбай» болгож ялга.
