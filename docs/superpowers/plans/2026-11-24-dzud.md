# Зудын эрсдэл: ажлын төлөвлөгөө

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Зудыг сайтын бусад эрсдэлтэй ижил, өдөр бүрийн 0.1° торон эрсдэл болгож, Sarul72-гүй түүхтэй хамт нийтлэх.

**Architecture:** `pipeline/dzud.py` өвлийн цас, хүйтэн, зуны NDVI, малын ачааллаас тогтмол жинтэй индекс гаргаж, ҮСХ-ны хорогдлоор тохируулсан магадлалыг 0–100 оноо болгоно. Үр дүн `data/gee/dzud/`-д тусдаа файлаар гарах тул одоогийн файлын бүтэц хэвээр. Хуудас `js/dzud.js`-ээр уншиж, одоогийн торон эрсдэлийн замаар (бүс, сум, талбайн цонх, таталт) харуулна.

**Tech Stack:** Python 3 + numpy (тооцоо), Earth Engine (өдөр тутмын ажил), цэвэр ES modules, Leaflet; шинэ JS сан байхгүй.

**Spec:** [docs/superpowers/specs/2026-11-24-dzud-design.md](../specs/2026-11-24-dzud-design.md)
